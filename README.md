# Board-Game
หัวข้อ ระบบจัดการบอร์ดเกมคาเฟ่ (Board Game Cafe Management) เป็นตัวเลือกที่น่าสนใจมากครับ และเมื่อตรวจสอบจากเอกสารเค้าโครงรายวิชา (Syllabus) ที่แนบมา พบว่าเนื้อหาของโปรเจกต์นี้สามารถนำไปเชื่อมโยงเพื่อเก็บคะแนนตามหัวข้อการเรียนการสอนได้อย่างครบถ้วนสมบูรณ์ครับนี่คือจุดที่โปรเจกต์นี้สอดคล้องกับวิชาของคุณ:การออกแบบ ER Diagram และ Relational Database
