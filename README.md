# Board Game Cafe - Web

เว็บจัดการบอร์ดเกมคาเฟ่ (Node.js + Express + SQL Server + Socket.IO)
เชื่อมต่อกับฐานข้อมูล `BoardGameCafeDB` ตัวเดียวกับที่ใช้ทำ coursework บน SQL Server โดยตรง
ทุกหน้าอัปเดตแบบ **เรียลไทม์** (ไม่ต้องกดรีเฟรช) และทุกการเขียนข้อมูลเรียก **Stored Procedure / Trigger เดิม** ในฐานข้อมูล

## สิ่งที่ต้องมีก่อนเริ่ม
- Node.js (แนะนำ v18+)
- SQL Server ที่มีฐานข้อมูล `BoardGameCafeDB` (รัน `boardgame_cafe_sqlserver.sql` แล้ว)
- เปิดใช้งาน **SQL Server Authentication** (mixed mode) และรู้รหัสผ่าน `sa`

## ขั้นตอนติดตั้ง

### 1. ฐานข้อมูล
- **สร้างใหม่:** เปิด `boardgame_cafe_sqlserver.sql` ใน SSMS แล้วกด **Execute** (⚠️ ลบฐานเดิมทิ้งแล้วสร้างใหม่พร้อมข้อมูลตัวอย่าง)
- **มีฐานข้อมูลอยู่แล้ว:** ไม่ต้องทำอะไร — ตอน `npm start` เชื่อมต่อครั้งแรก เว็บจะอ่าน `boardgame_cafe_sqlserver.sql` แล้วรันเฉพาะส่วน `CREATE OR ALTER` (Function / View / Trigger / Stored Procedure) ให้อัตโนมัติ **ไม่ลบข้อมูล** — ดูผลในหน้าต่าง npm start ที่บรรทัด `[db-upgrade]`
> ⚠️ `boardgame_cafe_sqlserver.sql` จะ **ลบฐานข้อมูลเดิมทิ้ง** แล้วสร้างใหม่ ถ้าไม่อยากเสียข้อมูลให้ใช้ไฟล์อัปเดตแทน

### 2. ตั้งค่าเชื่อมต่อฐานข้อมูล
คัดลอก `.env.example` เป็น `.env` แล้วแก้ให้ตรงกับเครื่อง:
```
DB_SERVER=127.0.0.1
DB_USER=sa
DB_PASSWORD=รหัสผ่าน sa ของคุณ
DB_NAME=BoardGameCafeDB
```

เพิ่มบรรทัดนี้ใน `.env` ด้วย (ข้อความสุ่มยาวๆ อะไรก็ได้ ใช้เซ็น cookie ของระบบ login):
```
SESSION_SECRET=ข้อความสุ่มยาวๆ
```

### 3. ติดตั้งและรัน
```
npm install
npm start
```

## เข้าสู่ระบบ
| ใคร | เข้าอย่างไร | ทำอะไรได้ |
|---|---|---|
| **พนักงาน** (แท็บ 🛠 พนักงาน) | `somchai` / `admin1234` หรือ `suda` / `admin1234` — **เปลี่ยนรหัสผ่านทันทีที่เมนูบนขวา** | สถานะโต๊ะ + เรียกคิว, เช็คเอาท์, เปลี่ยนเกมบนโต๊ะ, คืนเกมเช่า, รายได้, **จัดการข้อมูล (เพิ่ม/แก้ไข/ลบ)** |
| **ลูกค้า** (แท็บ 👤 ลูกค้า) | สมัครสมาชิกเองด้วยชื่อ นามสกุล เบอร์โทร + รหัสผ่าน แล้ว login ด้วยเบอร์โทร | จองโต๊ะ/เข้าคิว (ทีละ 1), เลือก/คืนบอร์ดเกมของโต๊ะตัวเอง, เช่าเกมกลับบ้าน, "บัญชีของฉัน" |
| ยังไม่ login | — | ดูหน้าบอร์ดเกมได้อย่างเดียว |

- รหัสผ่านเก็บเป็น **bcrypt hash** เท่านั้น (ไม่มีรหัสจริงในฐานข้อมูล) · ใส่ผิด 5 ครั้งติดล็อก 1 นาที
- ลูกค้าที่เคยจองที่ร้าน (พนักงานบันทึกเบอร์ไว้) สมัครด้วยเบอร์เดิมได้ ประวัติและแต้มยังอยู่
- ข้อมูลเรียลไทม์แยกตามสิทธิ์: ลูกค้าไม่เห็นชื่อ/เบอร์ของลูกค้าคนอื่น (เห็นแค่จำนวนคิว)
- เพิ่มพนักงานใหม่: INSERT ลง `tbl_employee` แล้วตั้ง `Username` + `PasswordHash` (สร้าง hash ด้วย `node -e "console.log(require('bcryptjs').hashSync('รหัส',10))"`)
เปิดเบราว์เซอร์ไปที่ **http://localhost:3000**

## หน้าเว็บ
### ฝั่งลูกค้า (login ด้วยเบอร์โทร)
- **`/booking` จองโต๊ะ / เช่าเกม** — ฟอร์มเดียว 2 โหมด
  - **🪑 เล่นที่ร้าน**: เลือกได้ทุกโต๊ะ — โต๊ะว่าง → จองทันที (`sp_CheckIn`) + เลือกเกมได้ 1 เกม (`sp_BorrowGameInStore`) · โต๊ะไม่ว่าง/มีคิว → **เข้าคิวรอโต๊ะนั้น** (`sp_AddToQueue`) · จองได้ทีละ 1 โต๊ะ/1 คิว
  - **🏠 เช่ากลับบ้าน**: เลือกเกม + วันคืน → ระบบคิดค่าเช่า+มัดจำ (`sp_RentOffsite`) · ครั้งแรกต้องกรอก **เลขบัตรประชาชน 13 หลัก** (บันทึกในบัญชี ครั้งต่อไปไม่ต้องกรอก)
  - ชำระเงิน / รับเกม / ตรวจบัตร ที่เคาน์เตอร์ · บิลที่ลูกค้าทำเองบันทึกพนักงานเป็น "Online Booking"
  - ด้านบนมีการ์ด "สถานะของฉัน": โต๊ะที่กำลังเล่น, คิวที่รอ (ยกเลิกได้), เกมที่เช่ากลับบ้านอยู่
- **`/me` บัญชีของฉัน** — โปรไฟล์ แต้ม สถานะตอนนี้ ประวัติการเล่นและการเช่า
- **`/games` 🎲 บอร์ดเกม (เลือกเกมทีหลัง)** — การ์ดเกมพร้อมรูป รายละเอียดย่อ วิธีเล่นแบบย่อ สต๊อกสด + ค้นหา/กรองจำนวนผู้เล่น/เฉพาะที่ว่าง
  - ลูกค้าที่มีโต๊ะอยู่กด **"หยิบเกมนี้เข้าโต๊ะ #x"** ได้เลย (`sp_BorrowGameInStore`) · อยากเปลี่ยนเกมกด **"คืนเกมนี้"** ก่อน (1 โต๊ะ 1 เกม)
  - ใช้ได้เฉพาะโต๊ะของตัวเอง (API `/api/my/borrow`, `/api/my/return-game` หาโต๊ะจากบัญชีที่ login — ส่งเลขโต๊ะคนอื่นมาไม่ได้)
  - เมนูบนแถบมีป้าย **"เลือกเกม"** เตือนเมื่อได้โต๊ะแล้วแต่ยังไม่ได้หยิบเกม

### ฝั่งพนักงาน (แท็บ 🛠 พนักงาน)
- **`/dashboard` สถานะโต๊ะ** — โต๊ะ ลูกค้า เวลาที่เหลือ, เกมบนโต๊ะ (**1 โต๊ะ 1 เกม**: คืนเกม / หยิบเกม), **ต่อเวลา** (`sp_ExtendTime` — โต๊ะเต็ม+มีคิว = ต่อไม่ได้), เช็คเอาท์ (`sp_CheckOut`)
  - **คิวรอโต๊ะ** อยู่ใต้ตาราง — โต๊ะที่ว่างแล้วกด "เรียกคิวแรกเข้านั่ง" (`sp_SeatNextInQueue`) หรือยกเลิกคิว (`sp_CancelQueue`)
- **`/rentals` เช่ากลับบ้าน** — บิลทั้งหมด (รวมที่ลูกค้าเช่าเอง) + ปุ่ม **คืนเกม** (สภาพเกม + ยอดคืนมัดจำ → `sp_ReturnOffsite`)
- **`/games`**, **`/revenue` รายได้** (สรุปรายวัน + รายละเอียดทุกบิล)
- **`/admin/data` 🗂 จัดการข้อมูล** — อ่าน/เขียน SQL Server โดยตรง อัปเดตอัตโนมัติทุก ~3 วินาที (เห็นการจองของลูกค้าและการแก้จาก SSMS ด้วย)
  - **ข้อมูลหลัก** (เพิ่ม / แก้ไข / ลบ): ลูกค้า · พนักงาน · หมวดเกม · บอร์ดเกม · โต๊ะ · แพ็กเกจเวลา
  - **รายการจอง** (แก้ไข / ลบ — เพิ่มใหม่ผ่านหน้าลูกค้า): การจองโต๊ะ · คิว · เช่ากลับบ้าน
  - ลบ = ลบในฐานข้อมูลจริงผ่าน `sp_AdminDelete…` ใน transaction เดียว และลบข้อมูลที่ผูกอยู่ด้วย (ก่อนลบจะแสดงว่ามีอะไรถูกลบบ้าง)
    - เกมที่ยังไม่คืนถูกคืนสต๊อก และโต๊ะที่ยังมีคนเล่นกลับเป็น "ว่าง" อัตโนมัติ (trigger)
    - ลบหมวดเกม → เกมในหมวดไม่ถูกลบ แค่กลายเป็น "ไม่มีหมวด"
    - ลบบัญชีตัวเอง / พนักงานระบบ Online Booking ไม่ได้ · บัญชีที่ถูกลบจะหลุดจากระบบทันที
  - บอร์ดเกม: แก้ "จำนวนกล่องทั้งหมด" แล้วจำนวน "ว่าง" ปรับตามให้เอง (ห้ามน้อยกว่าที่ถูกหยิบ/เช่าอยู่)
- พนักงาน**ไม่มีหน้าจองโต๊ะ/เช่า** — ลูกค้าทำเองทั้งหมด (ลูกค้า walk-in ให้สมัครสมาชิกบนเว็บก่อน)

## แก้ปัญหาที่พบบ่อย
- **ลบในหน้า "จัดการข้อมูล" แล้วขึ้น "ฐานข้อมูลยังเป็นเวอร์ชันเก่า"** → ปิดแล้วเปิด `npm start` ใหม่ (เว็บอัปเดตให้เอง) ถ้า `[db-upgrade]` แจ้งว่าไม่สำเร็จ ให้รัน `boardgame_cafe_sqlserver.sql` ใน SSMS
- **Invalid column name ...** (ตาราง/คอลัมน์ไม่ครบ) → ฐานข้อมูลเก่ามาก ให้รัน `boardgame_cafe_sqlserver.sql` ใหม่ใน SSMS
- **Cannot find module 'express-session' / 'bcryptjs'** → รัน `npm install` ใหม่
- **เชื่อมต่อไม่ได้ (ESOCKET / ECONNREFUSED)** → ใช้ `DB_SERVER=127.0.0.1` แทน `localhost` และเช็คว่า TCP/IP เปิดใน SQL Server Configuration Manager (แก้แล้วต้อง restart service)
- **Login failed for user 'sa'** → ตั้ง SQL Server เป็น "SQL Server and Windows Authentication mode" แล้ว restart service
- **ชื่อ instance ไม่ใช่ default** → ใส่ `DB_SERVER=localhost\\SQLEXPRESS` ใน .env

## โครงสร้างโปรเจกต์
```
Data_Base/
├── server.js                       # Express + HTTP server + Socket.IO
├── config/db.js                    # SQL Server connection pool (reconnect อัตโนมัติ)
├── routes/index.js                 # หน้าเว็บ + API (จองโต๊ะ/คิว/เช่า/คืน/หยิบเกม)
├── routes/admin.js                 # หน้า/API จัดการข้อมูล (เพิ่ม/แก้ไข/ลบ) — แอดมินเท่านั้น
├── services/adminData.js           # นิยามตาราง ฟอร์ม และการตรวจค่า ของหน้าจัดการข้อมูล
├── routes/auth.js                  # login / สมัครสมาชิก / logout / เปลี่ยนรหัสผ่าน
├── middleware/auth.js              # กันสิทธิ์: requireLogin / requireAdmin / requireCustomer
├── services/realtime.js            # ดึงสถานะรวม + broadcast ผ่าน Socket.IO ทุก 3 วินาที
├── views/                          # หน้า EJS
├── public/css/style.css
├── public/js/realtime.js           # ฝั่งเบราว์เซอร์: อัปเดตเรียลไทม์ + ฟอร์มทั้งหมด
├── boardgame_cafe_sqlserver.sql    # schema หลัก (ฉบับล่าสุด)
├── public/images/games/            # รูปประกอบเกม (SVG) — เปลี่ยนเป็นรูปถ่ายจริงได้
└── services/dbUpgrade.js           # ตอนเปิดเว็บ: สร้าง/อัปเดต Function, View, Trigger, SP จากไฟล์ SQL หลัก
```
